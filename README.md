# Carnet Muscu

Programme d'entraînement et carnet de charges, installable sur le téléphone (appli web hors-ligne).

- Ouvrir : https://box4075.github.io/carnet-muscu/
- Installer : Chrome → menu ⋮ → « Ajouter à l'écran d'accueil ».
- Les données restent sur le téléphone. Exporter une sauvegarde depuis l'onglet **Plus**.

Le programme se modifie dans `program.js`.
